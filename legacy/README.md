# Historical application sources

These files retain the original GUI, ArcGIS and development model implementations
for provenance. Several model scripts use the earlier twelve-factor/random-split
configuration and local study paths. They are not the entry point for the accepted
fourteen-factor spatial results. Use ../run_analysis.py and ../research/scripts/exp_lib.py.

The historical GUI split across Python/ArcGIS environments requires local setup;
some auxiliary GUI CLI modules referenced by AutoSlide_v3.py are absent from the
available source tree. The complete scientific modelling path is supplied through
the command line, rather than presenting this historical interface as a tested release.
